# 로컬 실험 워크벤치

패턴과 실험 조건을 파일로 관리하고 저장된 검증 결과를 조회하는 로컬 화면이다.
Python 표준 라이브러리와 브라우저만 필요하다. 화면 조회에는 GPU가 필요하지 않다.

## 시작과 사용

저장소 루트에서 실행한다.

```bash
python3 scripts/workbench.py
```

http://127.0.0.1:8765 에 접속한다. 종료는 서버 터미널의 Ctrl+C다.
포트가 사용 중이면 `--port 8766`으로 바꾸고 출력된 주소를 연다.

1. **메모리 패턴**: 새로 만들기 → 이름/파일명/32비트 상수 목록 → 저장.
   줄바꿈 또는 쉼표로 값을 구분한다. 순서와 중복 값을 유지하며 상수마다 전체 영역을 검사한다.
2. **실험 프리셋**: 저장한 패턴을 선택하고 원소 수·반복·기록 한도·주입·모니터링을 저장한다.
   예를 들어 33,554,432개 원소는 128 MiB다.
3. **실행 명령 복사**: 터미널에서 실행한다. CUDA 실행 파일 빌드는 README 절차를 따른다.
4. **실행 결과**: 새로고침 후 기록을 선택한다. 판정·설정·지표 그래프와 원시 로그를 확인한다.

파일은 `patterns/`, `profiles/`에 저장한다. 파일명을 바꾸면 새 파일을 만들며 원본은 남긴다.
저장하지 않은 편집이 있으면 이동 전에 확인한다. 다른 창이나 편집기에서 파일을 수정한 경우,
읽을 때의 SHA256과 현재 파일의 SHA256이 다르면 저장을 거부한다. 새로고침해서 변경분을 확인한다.
저장 완료 전에는 새 명령 복사를 막아 편집 중인 값과 실행 조건이 혼동되지 않게 한다.

실험 실행 시 Python 실행기가 입력 원본과 최종 설정을 결과 폴더에 복사한다.
나중에 프리셋을 바꿔도 과거 실험의 설정은 이 사본으로 확인할 수 있다.

## 책임과 표시 기준

| 구성 | 책임 |
|---|---|
| `web/` | 편집 폼, 실행 목록, 결과·지표 표현 |
| `scripts/workbench.py` | 로컬 HTTP API, 제한된 파일 저장·조회, 저장 충돌 검사 |
| `scripts/experiment_config.py` | CLI와 GUI가 공유하는 입력 검증 |
| `scripts/run_experiment.py` | GPU 프로그램 실행, 입력·환경·로그·지표 기록 |
| CUDA 프로그램 | 패턴 쓰기·주입·검사 및 CPU 독립 대조 |

GUI가 PASS/FAIL/ERROR를 새로 판정하지 않는다. `run.json`에 저장된 상태와 종료 원인을 표시한다.
FAIL은 검출된 데이터 불일치이며 의도한 소프트웨어 오류 주입에서도 나온다.
ERROR는 실행·대조 등의 오류다. 테스트 도구의 PASS와 검사 대상의 FAIL을 구분한다.

- 전체 실행 시간은 CPU 대조를 포함한 프로세스 시간이다. 커널 실행 시간이나 대역폭이 아니다.
- 지표의 미지원/오류/누락은 0으로 바꾸지 않는다. 유효한 값만 표시하고 누락 구간에서는 선을 끊는다.
- GPU가 여러 개 기록되면 장비를 선택할 수 있다. 조회된 지표는 해당 장비의 관측값이다.
- 로그와 telemetry는 파일당 앞부분 2 MiB까지 읽고 잘림을 표시한다. 전체 기록은 결과 폴더에 남아 있다.
- 실험 실행기 형식의 `run.json`만 목록에 포함한다. 성능 비교·테스트 묶음의 별도 manifest는 제외한다.
- 새로고침으로 저장된 기록을 다시 읽는다. 실행/중단 버튼, 실시간 진행률, 여러 실행 비교 화면은 후속 범위다.

서버는 `127.0.0.1`에만 연결한다. 저장 요청은 같은 출처와 세션 토큰을 확인하고,
정해진 파일명과 작업 공간 내부 경로만 허용한다. GPU 명령을 실행하는 HTTP API는 없다.

## 테스트

서버 검사 6개는 별도 설치 없이 실행한다.

```bash
python3 -m unittest discover -s tests/gui -v
```

브라우저 검사는 개발용 Playwright와 Chromium을 사용한다. GUI 실행 자체에는 이 설치가 필요 없다.

```bash
python3 -m venv build/ui-env
build/ui-env/bin/python -m pip install -r tests/gui/requirements-browser.txt
build/ui-env/bin/python -m playwright install chromium
build/ui-env/bin/python tests/gui/browser_smoke.py
```

9개 검사: 초기 로딩 중 조작 차단, 실제 저장 기록의 상태·그래프·로그, 중복 패턴 생성, 잘못된 값 저장 거부,
수정·명령 복사, 선택 패턴으로 프리셋 생성, 외부 편집 충돌, 작은 화면 배치, 브라우저 오류 확인.
편집은 임시 작업 공간에서만 수행한다. 실제 128 MiB 기준 실험 기록을 복사해 조회한다.
결과 폴더에는 판정과 소스 SHA256/사본, 화면 캡처가 남는다.

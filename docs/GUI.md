# 로컬 GUI 사용법

패턴·실험 조건을 편집하고 저장된 결과를 조회하는 화면이다. Python 표준 라이브러리와
브라우저만 필요하며 조회 자체에는 GPU가 필요하지 않다.

## 시작

저장소 루트에서 실행하고 http://127.0.0.1:8765 에 접속한다.

```bash
python3 scripts/workbench.py
```

포트가 사용 중이면 `--port 8766`으로 바꾸고 출력된 주소를 연다. 종료는 Ctrl+C다.

## 사용 순서

1. **메모리 패턴**: 새로 만들기 → 파일명·이름·패턴 방식·값 목록 입력 → 저장.
   줄바꿈 또는 쉼표로 구분한다. 각 값으로 정의한 패턴으로 전체 영역을 검사하며 순서와 중복을 유지한다.
2. **실험 프리셋**: 패턴 파일, 원소 수·반복·기록 한도·주입·모니터링 조건을 저장한다.
   33,554,432개 원소는 128 MiB다.
3. **실행 명령 복사**: 터미널에 붙여 넣어 실행한다. CUDA 프로그램 빌드는 [README](../README.md)를 따른다.
4. **실행 결과**: 새로고침 후 실행을 선택해 상태·설정·원시 로그·GPU 지표를 확인한다.

패턴은 `patterns/`, 프리셋은 `profiles/`에 저장한다. 형식과 옵션은 [입력 설정](INPUTS.md)에 있다.
파일명을 바꾸면 새 파일을 만들고 원본은 남긴다. CLI와 GUI는 동일한 입력 검증 함수를 사용한다.

## 편집과 결과 보존

저장하지 않은 변경이 있으면 화면 이동 전에 확인한다. 파일을 연 뒤 다른 창이나 편집기에서
내용을 바꾸면 SHA256 차이로 저장 충돌을 알린다. 새로고침해서 변경분을 확인한다.
편집 중에는 명령 복사를 비활성화한다. 저장 후 복사한 명령은 실행 시점의 파일을 읽는다.

실험 실행기는 입력 원문과 최종 설정을 결과 폴더에 복사한다. 과거 조건은 현재 프리셋 대신
이 사본으로 확인한다. GUI는 `run.json`의 판정을 표시하며 새로 계산하지 않는다.

## 표시 범위

- 실행기의 개별 실험을 검색·조회한다. 테스트/성능 비교 묶음과 PyTorch 기록은 별도 문서에서 확인한다.
- 전체 실행 시간은 CPU 대조를 포함한 프로세스 시간이다.
- 지표가 누락되면 0으로 채우지 않고 그래프 선을 끊는다. 기록된 GPU가 여러 개면 선택할 수 있다.
- 로그·telemetry는 파일당 앞부분 2 MiB까지 읽고 잘림을 표시한다. 전체 원문은 결과 폴더에 남는다.
- 새 기록은 새로고침으로 읽는다. 실행/중단 버튼, 실시간 진행률, 다중 실행 비교 화면은 제공하지 않는다.

서버는 127.0.0.1에만 연결하고, 저장 요청의 출처·토큰·파일명·작업 공간 내부 경로를 검사한다.
